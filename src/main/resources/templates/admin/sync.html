Trigger a season sync

This fetches weeks 1–18 of the regular season from Sleeper, accumulates per-player totals (PPR points, passing/rushing/receiving yards, TDs, kicker stats), and upserts everything into the database. Overall fantasy rankings are recalculated automatically.

After syncing, visit Players or Rankings to see the updated data.

Sync AI Predictions

Sends the selected season's stats to the Python ML model and stores projected fantasy points for the target season. The Python server must be running at localhost:8000 with trained models loaded.

Sync Opponent Data

Fetches the NFL schedule from ESPN's public API and tags each weekly stat with the opponent's team code. Run this for every season you have synced so the ML model can use opponent-adjusted strength as a feature. Takes ~30 seconds per season.
